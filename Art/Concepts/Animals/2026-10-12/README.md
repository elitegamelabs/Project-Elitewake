# Elitewake animal model reference set

This folder contains 54 AI-generated, full-body visual references intended to help artists and modelers establish original 3D creature proportions, silhouettes, anatomy, and surface detail.

The species names come from the named roster in **Elitewake_World_Resource_and_Ecology_Guide_v1.docx**, plus **House Cat** from the design reference and the named aquatic creatures. Duplicate species across regions are represented once. Fish, birds and other animals use simple studio backgrounds so their forms remain readable.

These images are concept references. They do not establish final species inclusion, regional placement, counts, behavior, drops, taming, balance, or production status. Several ecology placements remain candidates in the guide. Review each model against the authoritative design docs before implementation. The Siren is an original fictional creature concept.

Files are named by species. See `roster.json` for the category and guide-source note. Original generated source images were left untouched.
