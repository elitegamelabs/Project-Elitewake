# ELITEWAKE instructions for Grok

Welcome to the team (owner, October 22, 2026). ELITEWAKE is an Unreal Engine 5.8 C++ pirate survival and sailing game. Read these, in this order, before doing anything:

1. [Docs/TEAM_CHARTER.md](Docs/TEAM_CHARTER.md): **no locks, no claims, no ownership; everyone works freely**; how we log, hand out tasks and review each other.
2. [AGENTS.md](AGENTS.md): the project's standing owner requirements (they apply to every AI model, including you).
3. [Docs/OwnerDecisions/](Docs/OwnerDecisions/): the owner's decisions, newest first; start with `GAMEPLAY_FIXES_AND_FEATURES_2026-10-22.md` and `GAMEPLAY_DESIGN_DECISIONS_2026-10-22.md`.
4. [Docs/Delegation/GROK.md](Docs/Delegation/GROK.md): your task list. [Docs/Delegation/INBOX.md](Docs/Delegation/INBOX.md): the shared log; add an entry for every session.

Rules in one breath: never place a lock or claim on anything; never claim something works without a build and a Play check or test; do not delete files for good, force-push
or merge pull requests without the owner's approval; put your work on `main` or a visible branch and write it up in the inbox; keep the owner's decisions separate from your
suggestions (label suggestions as suggestions); Claude reviews pushed work and will correct or hand it back with notes, so write clearly what you did and did not verify.
