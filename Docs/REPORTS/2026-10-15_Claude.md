## 1. Escape OPTIONS menu, save and return to title — `dfbdc22`

**Owner request:** "You hit ESC and it brings up OPTIONS and under it SAVE GAME and MAIN MENU which will actually
take you back to the ELITEWAKE title screen."

- `Source/EW/EWOptionsWidget.*`: the menu (C++ UMG). OPTIONS title, SAVE GAME, MAIN MENU; Up/Down and Enter or the
  mouse; Escape or B closes. In multiplayer SAVE GAME is hidden (multiplayer has no manual save, per
  `MULTIPLAYER_RULES.md`).
- `AEWPlayerController::SetOptionsMenuOpen` (`EWPlayerController.cpp`): Escape opens it (Escape closes the map
  first if open). Single player pauses the world (`SetPause`). `ReturnToMainMenu` opens `/Game/Elitewake/Maps/Lvl_Title`.
- `Source/EW/EWSurvivorSave.*` (`UEWSurvivorSave`, slot `Survivor`): saves map, location, view, health, hunger,
  hydration, inventory with food ages, equipment, hotbar. `ApplyTo` restores it, giving the starter kit first so
  tools are never doubled. Single Player from the title resumes from it
  (`UEWGameInstance::ResumeSavedSurvivorOnArrival`, applied in `CompleteArrival`).
- DECIDED (delegated): one slot; Single Player always resumes when a save exists. World state (felled trees etc.)
  is not saved yet (M7).
- Verification: `Scripts/Verification/verify_options_menu_play.py` (9 checks, single-player Play via the new
  `EW_PLAY_STANDALONE=1` option in `EWEditorVerificationLibrary::StartVerificationPlaySession`).
- Note for testers: in the editor's in-window Play, Escape stops Play; use Standalone or a packaged build.
