## Reconciled items (not open again unless revised)

- Five regions replace the older four-region list. There is one NPC Port per region; all five Port islands remain unclaimable and uncontestable. Port locations/stocks are still open.
- Snow Leopards belong in Winter; Horses belong in Plains; Swamp has insects, spiders (including giant spiders) and reptiles. Counts, exclusive placement and statistics remain open.
- First sloop has two cannon hardpoints; it is a configuration decision, not an open question.
- Wooden starter tools cost 20 generic Wood each; Hide Waterskin costs 1 Hide plus 10 Thatch. The four starter recipes unlock after the innkeeper introduction.
- Four starter rewards include 250 Copper; currency ratios above are established.
- The Quartermaster's Journal lives in the Journal menu. Sails are not built during the prologue and require the Loom.
- Berries stay wild-only, static on bushes, fresh 20 real minutes, then an inedible toxic crafting resource.
- The squid is currently delegated-classified with the manta as a larger sea creature. This index records the current documentation and does not grant owner approval of the implementation values.
- Claiming is multiplayer-only. Contest expiry removes the existing flag and only then starts the challenger claim timer.

All code paths named above are pointers to inspect, not declarations of complete behavior. Where a code value is listed it is a working value unless marked owner-confirmed. Owners should answer decisions in the matching section of `DESIGN_REFERENCE.md`; then update affected tests and gameplay data.
